# 遺伝的アルゴリズム可視化アプリケーション

2次元の実数値関数を遺伝的アルゴリズムで最適化し、その収束過程をリアルタイムで可視化するWebアプリケーションです。

[https://mkatoo.github.io/ga-visualize/](https://mkatoo.github.io/ga-visualize/)

## 特徴

- Sphere・Rosenbrock・Ackley・Rastrigin・Beale関数の最小値を探索
- 世代ごとの個体分布を2D・3Dで表示
- 関数の地形をヒートマップ・等高線・3D曲面で表示
- 最良評価値・平均評価値の推移と、その世代までの最良値を表示
- 過去の世代を選ぶと、個体分布・グラフ・統計が連動
- 既知の最適解の位置・座標を表示

## 技術仕様

### 遺伝的アルゴリズム

- 個体数: 1-1000（デフォルト: 50）
- 変数の範囲
  - Sphere関数: x, y ∈ [-10, 10]
  - Rosenbrock関数: x, y ∈ [-2, 2]
  - Ackley関数: x, y ∈ [-5, 5]
  - Rastrigin関数: x, y ∈ [-5.12, 5.12]
  - Beale関数: x, y ∈ [-4.5, 4.5]
- 選択手法: トーナメント選択（サイズ: 3）
- 交叉手法: BLX-α交叉（α = 0.5）
- 突然変異: ガウシアン変異（突然変異率: 0.1）
- 世代数: 1-1000（デフォルト: 20）

### 技術スタック

- フロントエンド: SolidJS + TypeScript
- 可視化: Canvas API（2D）、Three.js（3Dを選択したときに読み込み）
- ビルドツール: Vite
- コード品質: Biome (linting, formatting)
- テスト: Vitest + Testing Library

## 操作方法

### 実行と設定

目的関数・個体数・世代数を設定して「開始」を押すと、探索が始まります。「詳細設定」では突然変異率・交叉率・トーナメントサイズを変更できます。

設定の数値入力はEnterまたは入力欄からフォーカスを移したときに確定し、Escapeで確定済みの値に戻せます。入力エラーがある間は開始・ステップ操作ができません。「設定を確認」でエラーのある入力欄に移動できます。

「一時停止」で探索を止め、「再開」で続けられます。「実行速度」を開くと、スライダーで1世代あたりの時間を調整できます。速度と表示方式は実行開始後も変更できます。

探索開始後は一時停止中や完了後も実験設定を変更できません。「リセット」で設定値を保って開始前に戻り、「もう一度実行」で同じ設定の探索を再実行できます。

「詳細設定を初期値に戻す」は詳細設定の3項目を初期値に戻します。

### 結果の確認

評価値の要約では表示世代の最良・平均評価値と、その世代までの最良評価値を確認できます。「結果の詳細」で表示世代の最良個体と、その世代までに見つかった最良個体の座標を確認できます。「座標の詳細」では丸める前の値を表示します。

既知の最適解は緑の×印、地形の評価値は色目盛りで確認できます。推移グラフの縦軸は「線形」「対数」を切り替えられます。0は対数で表せないため、グラフの下端に表示します。

地形の下にある履歴スライダーや「表示世代」の数値入力で過去の世代を選べます。推移グラフをタップしても選べます。世代を選ぶと探索が一時停止し、個体分布・評価値の要約・結果の詳細・グラフが選んだ世代に切り替わります。

「最新世代に戻る」で最新の結果を表示できます。探索の再開やステップ操作は最新世代から続けます。

「リセット」や「もう一度実行」を押すか、ページを再読み込みすると、以前の実行結果と履歴は消えます。

## 利用上の注意

- 3D表示にはWebGL 2が必要です。
- 「3D表示設定」で高さ・色の尺度、曲面の分割数、格子線を調整できます。「視点リセット」で初期視点に戻せます。
- 色目盛りの最大値は関数と探索範囲ごとに固定されます。地形の色と3Dの高さの対数尺度には `log(1 + 評価値)` を使い、目盛りには元の評価値を表示します。
- 3Dでは、近似した曲面から点が少し離れたり、谷底で隠れたりする場合があります。

## カスタマイズ

### アルゴリズムパラメータ

目的関数・個体数・世代数は実験設定から、突然変異率・交叉率・トーナメントサイズは詳細設定から調整できます。アプリ起動時の初期値を変更する場合は `src/genetic-algorithm.ts` の `DEFAULT_CONFIG` を編集してください。個体数・世代数・目的関数の初期値は `src/constants.ts` で定義しています。

- `populationSize`: 個体数（1-1000）
- `generations`: 世代数（1-1000）
- `mutationRate`: 突然変異率（0.0-1.0、デフォルト: 0.1）
- `crossoverRate`: 交叉率（0.0-1.0、デフォルト: 0.8）
- `tournamentSize`: トーナメントサイズ（1-1000、デフォルト: 3）
- `functionType`: 目的関数
- `bounds`: 変数の範囲（関数タイプに応じて自動設定）
