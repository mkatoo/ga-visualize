# 遺伝的アルゴリズム可視化アプリケーション

2次元の実数値関数を遺伝的アルゴリズムで最適化し、その収束過程をリアルタイムで可視化するWebアプリケーションです。

[https://mkatoo.github.io/ga-visualize/](https://mkatoo.github.io/ga-visualize/)

## 特徴

- Sphere・Rosenbrock・Ackley・Rastrigin・Beale関数の最小値を探索
- 世代ごとの個体分布と収束過程を2D・3Dでリアルタイムに表示
- 選択した関数の地形をヒートマップ・等高線・3D曲面で表示
- 最良評価値・平均評価値の推移をグラフで表示
- 世代ごとの個体分布を振り返る際に、グラフ・統計・2D・3Dの表示が連動
- 各世代の最良値と、その世代までに見つかった最良値を区別して表示
- 既知の最適解の位置・座標を表示

## 技術仕様

### 遺伝的アルゴリズム

- 個体数: 1-1000（デフォルト: 50）
- 変数の範囲
  - Sphere関数: x, y ∈ [-10, 10]
  - Rosenbrock関数: x, y ∈ [-2, 2]
  - Ackley関数: x, y ∈ [-5, 5]
  - Rastrigin関数: x, y ∈ [-5.12, 5.12]
  - Beale関数: x, y ∈ [-4.5, 4.5]
- 選択手法: トーナメント選択（サイズ: 3）
- 交叉手法: BLX-α交叉（α = 0.5）
- 突然変異: ガウシアン変異（突然変異率: 0.1）
- 世代数: 1-1000（デフォルト: 20）

### 技術スタック

- フロントエンド: SolidJS + TypeScript
- 可視化: Canvas API（2D）、Three.js（3Dを選択したときに読み込み）
- ビルドツール: Vite
- コード品質: Biome (linting, formatting)
- テスト: Vitest + Testing Library
- スタイリング: CSS3

## 操作方法

### 実行と設定

操作欄には上から順に、実行状態と進行状況、実行ボタン、アニメーション速度、実験設定を表示します。画面幅が狭いときは実行状態・進行状況・実行ボタンを画面下部にまとめて固定し、地形やグラフを見ている間も一時停止や完了を確認できます。

目的関数・個体数・世代数を設定して「開始」を押すと、探索が始まります。

個体数・世代数は入力欄からフォーカスを移すか、Enterを押すと反映されます。入力途中では個体分布を再生成しません。Escapeを押すと、確定済みの値に戻せます。

値が範囲外の場合や入力欄が空の場合は理由を表示します。正しい値を入力するまで開始・ステップ操作を無効にします。

実験設定を閉じても、見出しと実行ボタンの近くに入力エラーを表示します。「設定を確認」を押すと、エラーのある最初の入力欄に移動します。

「一時停止」で探索を止め、「再開」で続けられます。指定した世代数まで進むと探索が完了し、見つかった最良評価値を表示します。「もう一度実行」を押すと、同じ設定で初めから探索をやり直します。

探索を開始したあとは、一時停止中や完了後も目的関数・個体数・世代数を変更できません。設定を変更するには「リセット」を押して開始前の状態に戻します。アニメーション速度や表示方式は実行を開始したあとも変更できます。

アニメーション速度は実験設定を閉じていても調整できます。スライダーを右に動かすほど速くなり、左端は2秒／世代、右端は0.05秒／世代です。現在の1世代あたりの時間が表示され、実行中に速度を変更してもすぐに反映されます。スライダーを動かし続けている間も、探索は進みます。

### 結果の確認

地形の上の要約に、表示中の世代番号と、最良評価値・平均評価値・その世代までの最良評価値をまとめて表示します。推移グラフの凡例では最良評価値を実線、平均評価値を破線で示します。

地形と推移グラフの下にある「結果の詳細」は初期状態では閉じています。開くと、表示中の世代の最良個体の座標と、その世代までに見つかった最良個体の座標を確認できます。これまでの最良個体については発見した世代も表示します。画面幅が狭いときは両方の結果を上下に並べます。

座標は小数点以下3桁で表示します。「座標の詳細」を開くと、丸める前の値を確認できます。表示する世代を切り替えると、詳細欄の開閉状態はそのままで、内容が選んだ世代に切り替わります。

既知の最適解は小さな緑の×印で示し、凡例にその座標を表示します。描画領域の右側にある色目盛りで、地形の色に対応する評価値を確認できます。狭い画面では色目盛りを地形の下に横置きします。2Dの軸ラベルや個体の点は、画面サイズが変わっても読み取れる大きさを保ちます。

推移グラフは第0世代から設定した最終世代までの区間を表示します。縦軸の尺度は「線形」「対数」の2つのボタンで切り替えられます。選択中のボタンを強調表示し、初期状態では「線形」が選ばれています。「対数」を押すと、収束後の小さな評価値の変化を確認しやすくなります。0は対数で表せないため、グラフの下端に表示します。尺度を切り替えても、選択した世代やGAの評価値は変わりません。

地形上部の共通ツールバーでスライダーを動かすか、「表示世代」に世代番号を入力すると、表示する世代を選べます。

数値入力はEnterまたは入力欄からフォーカスを移したときに確定します。入力値は確定するまで表示世代に反映されず、入力しても探索は一時停止しません。Escapeを押すと、表示中の世代番号に戻せます。範囲外の値や小数、空欄にはエラーを表示します。スライダーは動かすとすぐに表示世代が切り替わります。

グラフの描画範囲をタップして選ぶこともできます。グラフ上でスクロールしても、世代を選ぶ操作にはなりません。

世代を選ぶと探索が一時停止し、個体分布・上部の要約・結果の詳細・グラフの内容が選んだ世代に切り替わります。

「最新世代に戻る」で最新の結果を表示できます。探索を再開したり1世代進めたりする場合は、最新世代から続けます。

「リセット」や「もう一度実行」を押すか、ページを再読み込みすると、以前の実行結果と履歴は消えます。

## 利用上の注意

- 色目盛りの最大値は関数と探索範囲ごとに固定され、世代によって変化しません。
- 地形の色と3Dの高さを対数尺度で表す際は `log(1 + 評価値)` を使います。色・高さの目盛には元の評価値を表示します。
- 3D表示中に地形の下の「3D表示設定」を開くと、高さ・色の尺度、曲面の分割数、格子線、視点リセットを操作できます。「高さ・色の尺度」を変更すると、3D地形の高さと色、色目盛りの尺度がまとめて切り替わります。GAの評価値は変わりません。
- 3Dではドラッグを離すと、回転が徐々に止まります。マウスやタッチで「視点リセット」を押すと、200msで初期視点に戻ります。キーボードで操作した場合や、端末で動きを減らす設定を有効にしている場合は、視点をすぐに反映します。
- 3D表示にはWebGL 2が必要です。
- 3Dでは、近似した曲面から点が少し離れたり、谷底で隠れたりする場合があります。

## カスタマイズ

### アルゴリズムパラメータ

`src/genetic-algorithm.ts` の `DEFAULT_CONFIG` を変更すると、次のパラメータを調整できます。

- `populationSize`: 個体数（1-1000）
- `generations`: 世代数（1-1000）
- `mutationRate`: 突然変異率（0.0-1.0、デフォルト: 0.1）
- `crossoverRate`: 交叉率（0.0-1.0、デフォルト: 0.8）
- `tournamentSize`: トーナメントサイズ（デフォルト: 3）
- `functionType`: 目的関数
- `bounds`: 変数の範囲（関数タイプに応じて自動設定）
