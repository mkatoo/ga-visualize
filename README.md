# 遺伝的アルゴリズム可視化アプリケーション

2次元の実数値関数を遺伝的アルゴリズムで最適化し、その収束過程をリアルタイムで可視化するWebアプリケーションです。

[https://mkatoo.github.io/ga-visualize/](https://mkatoo.github.io/ga-visualize/)

## 特徴

- Sphere・Rosenbrock・Ackley・Rastrigin・Beale関数の最小値を探索
- 世代ごとの個体分布と収束過程を2D・3Dでリアルタイムに表示
- 選択した関数の地形をヒートマップ・等高線・3D曲面で表示
- 最良評価値・平均評価値の推移をグラフで表示
- 世代ごとの個体分布を振り返る際に、グラフ・統計・2D・3Dの表示が連動
- 各世代の最良値と、その世代までに見つかった最良値を区別して表示
- 既知の最適解の位置・座標を表示

## 技術仕様

### 遺伝的アルゴリズム

- 個体数: 1-1000（デフォルト: 50）
- 変数の範囲
  - Sphere関数: x, y ∈ [-10, 10]
  - Rosenbrock関数: x, y ∈ [-2, 2]
  - Ackley関数: x, y ∈ [-5, 5]
  - Rastrigin関数: x, y ∈ [-5.12, 5.12]
  - Beale関数: x, y ∈ [-4.5, 4.5]
- 選択手法: トーナメント選択（サイズ: 3）
- 交叉手法: BLX-α交叉（α = 0.5）
- 突然変異: ガウシアン変異（突然変異率: 0.1）
- 世代数: 1-1000（デフォルト: 20）

### 技術スタック

- フロントエンド: SolidJS + TypeScript
- 可視化: Canvas API（2D）、Three.js（3Dを選択したときに読み込み）
- ビルドツール: Vite
- コード品質: Biome (linting, formatting)
- テスト: Vitest + Testing Library
- スタイリング: CSS3

## 操作方法

### 実行と設定

操作欄には実行状態と進行状況、実行ボタン、アニメーション速度、実験設定を上から順に表示します。画面幅が狭いときは実行ボタンを画面下部に固定します。

目的関数・個体数・世代数を設定し、「開始」を押すと探索を始めます。

「一時停止」で探索を止め、「再開」で続けられます。指定した世代数まで進むと探索が完了し、見つかった最良評価値を表示します。「もう一度実行」を押すと、同じ設定で初めから探索をやり直します。

探索を開始すると、一時停止中や完了後も目的関数・個体数・世代数を変更できません。設定を変更するには「リセット」で開始前に戻します。アニメーション速度や表示方式は実行を開始したあとも変更できます。

アニメーション速度は実験設定を閉じていても調整できます。スライダーを右に動かすほど速くなり、左端は2秒／世代、右端は0.05秒／世代です。現在の1世代あたりの時間が表示され、実行中の速度変更もすぐに反映されます。

### 結果の確認

地形の上にある「第○世代の結果」で、表示中の世代番号・最良評価値・最良個体の座標・平均評価値をまとめて確認できます。最良評価値と平均評価値の横にある実線・破線は推移グラフの線に対応しています。

グラフ下の「第○世代までの最良評価値」にはその世代までに見つかった最良個体の評価値・座標・発見した世代を表示します。

既知の最適解は小さな緑の×印で示し、凡例にその座標を表示します。描画領域の右側にある縦の色目盛りで、地形の色に対応する評価値を確認できます。

推移グラフは縦軸を線形尺度に固定し、第0世代から設定した最終世代までの区間を表示します。

地形上部の共通ツールバーでスライダーを動かすか、「表示世代」に世代番号を入力すると、表示する世代を選べます。グラフをタップして選ぶこともできます。世代を選ぶと探索が一時停止し、その世代の個体分布・統計・グラフを表示します。「最新世代に戻る」で最新の結果を表示できます。探索を再開したり1世代進めたりする場合は、最新世代から続けます。

「リセット」や「もう一度実行」を押すか、ページを再読み込みすると、以前の実行結果と履歴は消えます。

## 利用上の注意

- 色目盛りの最大値は関数と探索範囲ごとに固定され、世代によって変化しません。
- 地形の色と3Dの高さを対数尺度で表す際は `log(1 + 評価値)` を使います。色・高さの目盛には元の評価値を表示します。
- 3Dの「高さ・色の尺度」で地形の高さと色、色目盛りに使う尺度をまとめて切り替えられます。GAの評価値は変わりません。
- 3D表示にはWebGL 2が必要です。
- 3Dでは、近似した曲面から点が少し離れたり、谷底で隠れたりする場合があります。

## カスタマイズ

### アルゴリズムパラメータ

`src/genetic-algorithm.ts` の `DEFAULT_CONFIG` を変更すると、次のパラメータを調整できます。

- `populationSize`: 個体数（1-1000）
- `generations`: 世代数（1-1000）
- `mutationRate`: 突然変異率（0.0-1.0、デフォルト: 0.1）
- `crossoverRate`: 交叉率（0.0-1.0、デフォルト: 0.8）
- `tournamentSize`: トーナメントサイズ（デフォルト: 3）
- `functionType`: 目的関数
- `bounds`: 変数の範囲（関数タイプに応じて自動設定）
