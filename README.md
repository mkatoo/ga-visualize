# 遺伝的アルゴリズム可視化アプリケーション

2次元の実数値関数を遺伝的アルゴリズムで最適化し、その収束過程をリアルタイムで可視化するWebアプリケーションです。

[https://mkatoo.github.io/ga-visualize/](https://mkatoo.github.io/ga-visualize/)

## 特徴

- 複数の関数を対象に最小値を探索
  - Sphere関数: f(x,y) = x² + y²
  - Rosenbrock関数: f(x,y) = (1-x)² + 100(y-x²)²
  - Ackley関数: f(x,y) = -20·exp(-0.2·√((x²+y²)/2)) - exp((cos(2πx)+cos(2πy))/2) + 20 + e
  - Rastrigin関数: f(x,y) = 20 + x² - 10·cos(2πx) + y² - 10·cos(2πy)
  - Beale関数: f(x,y) = (1.5-x+xy)² + (2.25-x+xy²)² + (2.625-x+xy³)²
- 世代ごとの個体分布と収束過程を2D・3Dでリアルタイムに表示
- 選択した関数の評価値を背景のヒートマップと等高線で表示
- 3Dでは評価値を曲面の高さとして表示し、回転・ズーム・格子線表示で地形と個体を確認
- 最良適応度・平均適応度の推移をグラフで表示
- 画面上で実行を制御し、設定を変更
  - アニメーション速度の調整、1世代ずつのステップ実行
  - 個体数・世代数・最適化関数をリアルタイムに変更
  - 入力値を自動で検証し、有効範囲内に補正（クランプ）

## 技術仕様

### 遺伝的アルゴリズム

- 個体数: 1-1000（デフォルト: 100）
- 変数の範囲
  - Sphere関数: x, y ∈ [-10, 10]
  - Rosenbrock関数: x, y ∈ [-2, 2]
  - Ackley関数: x, y ∈ [-5, 5]
  - Rastrigin関数: x, y ∈ [-5.12, 5.12]
  - Beale関数: x, y ∈ [-4.5, 4.5]
- 選択手法: トーナメント選択（サイズ: 3）
- 交叉手法: BLX-α交叉（α = 0.5）
- 突然変異: ガウシアン変異（突然変異率: 0.1）
- 世代数: 1-1000（デフォルト: 50）

### 技術スタック

- フロントエンド: SolidJS + TypeScript
- 可視化: Canvas API（2D）、Three.js（3D、選択時に読み込み）
- ビルドツール: Vite
- コード品質: Biome (linting, formatting)
- テスト: Vitest + Testing Library
- スタイリング: CSS3

## 使い方

### 基本操作

1. ドロップダウンから最適化関数を選択
2. 個体数と世代数を設定
   - 個体数（1-1000）
   - 世代数（1-1000）
   - 実行中はパラメータを変更できない
3. ボタンで実行を制御
   - 開始: 遺伝的アルゴリズムの自動実行を開始
   - 停止: 実行を一時停止
   - ステップ: 1世代ずつ手動で実行
   - リセット: 初期状態に戻す
4. スライダーでアニメーション速度を調整（50ms〜2000ms）
5. 可視化パネル上部の「2D」「3D」で表示を切り替え（実行中も利用可能）

## 可視化の見方

### メイン可視化パネル

- 青い点（白い縁取り）: 通常の個体の位置
- 赤い点（白い縁取り）: 各世代の最良個体（適応度が最小の個体）。他の個体と重なっても手前に表示
- 背景色: 評価値が低い領域（良い）は紫で表示し、高い領域（悪い）ほど緑から黄色に近づく
- カラーバー: 背景色に対応する評価値を表示。色の尺度は関数と探索範囲ごとに固定され、世代によって変化しない
  - Sphere・Ackley・Rastriginは線形目盛
  - Rosenbrock・Bealeは最小値付近の違いを見やすくするため、対数目盛（`log(1 + 評価値)`）を使用。目盛の数値は元の評価値
- 等高線: 背景色に重ねて選択した関数の地形を表示
- 座標軸: X軸・Y軸の数値スケール

### 3D表示

「3D」を選ぶと、2変数関数 `f(x, y)` を高さ `z = f(x, y)` の曲面として表示します。低い場所ほど良い解です。

- 左ドラッグで回転、ホイールでズーム、右ドラッグで平行移動。Canvasにキーボードのフォーカスを当てると矢印キーでも移動できます。
- タッチでは1本指で回転、2本指でズーム・移動。ページをスクロールするときは描画領域の外を操作してください。
- 「視点リセット」で地形全体が見える位置に戻ります。世代が更新されても視点を保ちます。同じ関数・探索範囲なら、2Dから3Dに戻ったときも前の視点を復元します。関数・探索範囲を変えると視点をリセットします。
- 「高さの尺度」で線形と対数（`log(1 + f)`）を切り替えます。初期設定はRosenbrock・Bealeが対数、その他が線形です。目盛には元の評価値を表示します。高さを切り替えても色の尺度とGAの評価値は変わりません。
- 山の裏の点は隠れますが、最良個体の赤いリングは地形の裏でも表示します。「格子線のみ」でも個体の分布を確認できます。
- 描画が重い場合は「64（軽量）」を選択できます。点は近似した曲面から少し離れたり、谷底で隠れたりする場合があります。

3D表示にはWebGL 2が必要です。3Dを表示できない場合は、集団と世代を保って2Dに戻ります。「3D」で再試行できます。

### 統計情報

- 世代: 現在の世代数
- 最良個体: 座標と適応度を詳しく表示
- 平均適応度: 全個体の平均適応度

### 適応度推移グラフ

- 赤線: 各世代の最良適応度の推移
- 青線: 集団全体の平均適応度の推移

## カスタマイズ

### アルゴリズムパラメータ

`src/genetic-algorithm.ts` の `DEFAULT_CONFIG` を変更すると、次のパラメータを調整できます。

- `populationSize`: 個体数（1-1000）
- `generations`: 世代数（1-1000）
- `mutationRate`: 突然変異率（0.0-1.0、デフォルト: 0.1）
- `crossoverRate`: 交叉率（0.0-1.0、デフォルト: 0.8）
- `tournamentSize`: トーナメントサイズ（デフォルト: 3）
- `functionType`: 最適化関数
- `bounds`: 変数の範囲（関数タイプに応じて自動設定）

### UI制約

- 個体数・世代数の範囲は `ga-app.tsx` で定義されている定数で制御される
- 入力値は自動的に有効範囲内にクランプされる
- 実行中はパラメータの変更が無効化される

- 2D・3D共通の座標変換、固定尺度、線形・対数の高さと逆変換
- 表示切り替え時の実行状態・集団・視点の維持
- 3D読み込みの中断・失敗、初期化失敗、コンテキスト喪失時の2D復帰
